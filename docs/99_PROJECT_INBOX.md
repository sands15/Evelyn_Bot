## 검토·조정 중

### Live2D 꼬리 S자 idle wave

- 작성일: 2025-08-03
- 최근 검토일: 2026-08-13
- 종류: 아이디어
- 내용: 이블린의 꼬리가 s자 형태로 계속 움직였으면 좋겠음
- 관련 문서 또는 코드: [참고 영상](https://www.youtube.com/watch?v=SEt9-YtG0Ro&t=1s),
  `docs/assets/evelyn-live2d.js`, `tests/ui/test_control_page_live2d_assets.py`
- 검토 결과: 2026-08-12 완료 판정은 잘못됐다. 2026-08-13 참고 영상을 직접
  확인한 결과 핵심은 뿌리의 주동작, 뒤 관절의 겹침 지연, 반전 뒤 tip의 짧은 관성,
  S와 7 실루엣의 교대였다. 기존 구현은 root를 ±8.8도로
  왕복시키고 나머지 분절이 앞 각도의 78~82%를 따라가서, S자보다 꼬리 전체가
  뿌리를 축으로 그네처럼 움직였다. 위치가 변한다는 이전 검증도 S 실루엣을
  증명하지 못했다.
- 현재 조정: root만 ±6.5도의 넓은 호로 구동하고 뒤 6개 absolute heading이 앞 heading을
  spring으로 지연 추종한다. idle에서는 같은 7개 관절에 먼저 쓰인 native physics 값을
  끝으로 커지는 인접 heading 차이로 대체하고, speaking 전환 때만 native physics로 부드럽게 돌아간다.
  링크의 짧은 overlap timing에 맞춰 위상·spring·damping 시간을 함께 3.75배 압축했다.
  실행 중 8799의 실제 모델 샘플은 한 주기 3.721초, heading 반전 지연이
  root→tip `[0, 0.063, 0.119, 0.180, 0.259, 0.339, 0.400]`초였다.
- 위치·vertex·render order는 바꾸지 않았다. 컴파일된 모델에서 꼬리 몸통이 가려지는 문제는
  전체 노출을 원할 때의 별도 자산 과제이지, 이번 움직임 교정의 해법으로 섞지 않는다.
- Live2D asset 17개·전체 UI 191개와 실제 8799 browser probe가 통과했다. 사용자의 최종 육안 확인과
  필요하면 속도·진폭 미세 조정이 남아 있어 아직 완료로 승격하지 않는다.
