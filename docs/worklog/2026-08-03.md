  보존하고 검증된 source에서 실행을 복구했다. 해당 WIP는 변경 테스트 78개 중
  기존 Memory Vault 테스트 4개가 실패하므로 현재 실행 source에 포함하지 않았다.
- 로컬 전용 재빌드가 사용하지 않는 Discord 이미지와 `torch`까지 빌드하던 경로를
  수정했다. 기본 빌드는 Bot API, Control Page, Vision만 갱신하고 Discord 유지

  문제는 Control Page의 content-free 공개 Bridge projection을 검사하도록 수정했다.
