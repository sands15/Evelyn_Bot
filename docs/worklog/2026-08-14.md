## Hostile P0에서 full tactical P1으로 단일 인계

- 근접 hostile P0가 끝난 직후 band event가 다시 P0를 선점해 `handle_hostile` P1을 굶기는 경합을
  `hostileReflexHandoffPending`과 단일 50ms 재검사 timer로 닫았다. P1 callback이 실제 입장하기 전
  close threat가 남아 있으면 정확히 하나의 bounded P0 또는 하나의 재검사 timer가 보호를 유지한다.
  ActionManager가 기다리는 동안과 callback 없이 busy 결과를 반환한 뒤에도 보호와 재입력을 유지하고,
  callback 입장·위협 소멸·다른 결정·disconnect에서만 pending을 소비한다.
- P1 `action_started_at_ms`는 실제 callback 입장 시각으로 기록하고, active P0 종료를 기다린 뒤 현재
  hostile snapshot을 다시 만들어 표적·거리·전술 경험이 오래된 선택 시점 값에 묶이지 않게 했다.
  projectile P0 완료도 같은 guard를 다시 깨우며, `escape_to_surface`는 건강 저하와 hostile wake에
  cooperative interrupt된다. initial hostile/projectile P0 tail 오류는 fixed failed result로 수렴한다.
- event storm, idle/busy 인계, 실제 ActionManager 1-poll 입장과 resolved no-callback 거절, future cooldown,
  immediate movement failure, projectile 경합, zombie→skeleton 교체, disconnect를 전용 reflex 24개로
  고정했다. 최종 image build에서 planner 32개, 통합 Node 182개와 runtime-lint/combat/latency verifier가
  모두 통과했다. 이미지 digest는 `sha256:4072333cdd6a2c33504482359b625c9ce48fa3b2b4d9d22d8fc63fbed2ce097a`다.
