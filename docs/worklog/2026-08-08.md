# 2026-08-08 작업 기록

## 기본 TTS OmniVoice live 전환

- 시작 전 마지막 `evelyn-tts`는 VoxCPM2 image의 종료된 unhealthy container였고
  host 8880은 응답하지 않았다. OmniVoice source 20개와 고정 model snapshot 13개의
  SHA-256, Evelyn clone profile 존재, GPU 여유 공간을 다시 확인했다.
- 사용자 소유 `docs/99_PROJECT_INBOX.md` 복원본은 별도 commit `2f97223`으로 보존했고,
  OmniVoice 30개 파일은 `485c81d`로 분리했다. 기존 stash는 pop/drop하지 않았다.
- source revision `485c81d480f45dba4935a26ebb874d11e2f5931a`에서 recipe
  `evelyn-omnivoice-tts:recipe-7cfc51e96088`을 build했다. image 내부 source allowlist와
  Evelyn privacy patch 적용이 다시 통과했다.
- TTS 단일 서비스만 recreate했다. exact OmniVoice health와 Docker health가 통과했고,
  model/profile cache는 read-only, CUDA는 RTX 5090에서 사용 가능함을 확인했다.
- 앱 fallback을 거치지 않은 실제 Evelyn clone sentence stream은 HTTP 200과 24 kHz
  mono 16-bit little-endian PCM 101,280 bytes(약 2.11초)를 728 ms에 반환했다.
  응답은 메모리에서 형식과 길이만 확인하고 즉시 폐기했다.
- profile API는 `has_ref_text=true`만 공개하고 `ref_text` 원문을 반환하지 않았다.
  실제 합성 뒤 운영 로그에서도 probe text, reference path, session/turn 식별자가
  검출되지 않았다. raw audio, transcript, 로그 원문은 문서나 보고서에 저장하지 않았다.

## 정상 실행과 로컬 음성 연속성

- 정상 launcher가 기존 Bot API·Control Page image의 내장 revision `7c4770e`를 당시
  clean HEAD와 비교하지 않고 `--no-build`로 재사용하던 결함을 확인했다. 두 서비스는
  source gate에서 503을 반환해도 기존 port-only wait가 성공으로 오인할 수 있었다.
  launcher는 이제 missing/stale image를 allowlist builder로 갱신하고 Bot API와 Control
  Page의 exact source identity `/health`가 통과한 뒤에만 Supervisor를 시작한다.
- 첫 실제 재빌드는 optional `BuildContexts`를 StrictMode에서 속성으로 읽는 builder
  결함을 드러냈다. 누락 key를 안전한 hashtable 조회로 바꾼 뒤 같은 정상 사용자 경로를
  재실행했다. `start_local.bat --background`가 exit 0으로 끝났고 공식 runtime checker에서
  Control Page, Bot API, LLM 3개, OmniVoice, STT, Vision과 Local Bridge가 모두 ready였다.
- Local Bridge는 mic OFF, output ready, clone warmup 완료(564.1 ms), error count 0,
  playback count 0이었다. 실제 마이크 캡처나 스피커 재생은 하지 않았다.
- OmniVoice HTTP PCM write는 기존 cancellation-safe writer를 재사용해 blocking write가
  끝날 때까지 단일 playback owner를 유지한다. clone HTTP 200이 빈 PCM일 때는 아직
  재생이 시작되지 않은 경우에만 기존 `auto` 후보를 시도하며 부분 재생 뒤에는 재시도하지
  않는다. 변경 후 voice 608개(skip 5), runtime 756개(skip 4)가 통과했다.
