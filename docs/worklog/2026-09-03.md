## Personal Local Voice soft endpoint/reopen design

### Verified current boundary

- The standard personal Local Bridge still ends an utterance at 500 ms of silence. Its 500 ms audio
  chunk is not a reopen/merge contract.
- ASR stream `finish` removes the server session. The Bot chat path can consume admission and durable
  ingress before Main inference, so cancelling a 300 ms chat request cannot roll back every effect.
- No general 300 ms + 500 ms ordinary-input reopen implementation was found in the current source or
  Git history. Existing barge-in is a separate playback-interruption contract.

### Approved design checkpoint

- The Local target is now 300 ms soft endpoint plus an additional 500 ms grace. Soft endpoint keeps
  one capture generation, full PCM, and one ASR session; resumed speech invalidates the draft and
  continues the same utterance without transcript concatenation.
- With no resume, hard commit occurs at about 800 ms. Only a side-effect-free prepare transaction may
  overlap the grace. Exact promote commits admission and the accepted user row once, then keeps the
  current playback-ACK boundary for assistant history, continuity, memory, and background work.
  Tool/memory/action routes, mismatch, or uncertainty use the ordinary path after hard commit.
- Discord, qualified barge-in, model/quantization, dependencies, and current runtime configuration are
  unchanged. Source implementation, tests, and live microphone activation were explicitly deferred.
