## Completed-turn permanent stall and journal-only crash recovery

- bare `to_thread` filesystem stall을 임의 timeout으로 감싸지 않고, stdlib warm child에 default artifact
  primitive를 위임했다. nonce/request/sequence `READY -> PREPARED -> COMMIT|ABORT`, bounded frame/path,
  minimal environment와 parent-death watcher를 사용한다. timeout/disconnect는 terminate/kill/wait 뒤 exact
  temporary cleanup과 canonical disk-first reconciliation을 수행하며 mutation을 blind retry하지 않는다.
- Main checkpoint와 authenticity, Discord/Fast ingress, FastAction에 shared worker/deadline을 연결했다.
  pre-replace permanent stall, post-replace response stall, bounded read retry, worker hard-exit/replacement,
  Windows base executable PID ownership, credential 비상속, relative path 거부와 parent hard-death를 fault worker로
  고정했다. actual ingress write가 checkpoint RLock 안에서 멈춰도 bounded failure 뒤 다음 commit이 진행됐다.
- post-checkpoint Discord journal과 FastAction finish/interrupted도 self-scoped했다. write outcome error 뒤에는
  authoritative journal/head/external anchor를 다시 읽고 verified current 또는 one-generation lag에서만 재개한다.
  transient replacement read stall은 retryable이며 schema/hash/auth mismatch는 fail-closed한다.
- restart `delivery_succeeded` commit은 journal terminal marker를 checkpoint의 `before_commit`에 결박했다.
  marker-only active/empty/unkeyed-fresh predecessor를 exact turn으로 recommit하고, checkpoint 뒤 completion crash는
  generation을 다시 올리지 않는다. same-turn conflicting pair/receipt/user-only tail, wrong receipt generation과
  keyed fresh missing head를 거부하고 검증 실패 시 speculative live store를 exact snapshot으로 되돌린다.
  Main startup은 ingress recovery 뒤 owner-ready·generation-0·missing-head일 때만 empty bootstrap한다.
- status는 artifact mutation 전에 content-free in-flight/count/deadline 게시를 best-effort로 시도한다. Runtime
  Errors reader는 마지막으로 성공한 heartbeat로 stall age를 갱신하고 private/public allowlist를 거쳐 stalled
  warning을 제공한다.
- 검증: journal/restart narrow 81 passed와 subtests 3, 관련 통합 439 passed, 1 skipped와 subtests 57,
  canonical `python -m pytest -q` 4,188 passed, 22 skipped, 1 warning과 subtests 1,149(172.82초)가 통과했다.
  독립 최종 재검토 49 passed, subtests 3과 production compile, main 2,500줄/최대 158자 guard도 통과했다.
  후속 문서 대조에서 lock 대기/request exchange, surviving/replacement cleanup과 best-effort status 경계를
  source에 맞게 교정했고 재검토에서 직접 모순이 남지 않았다.
  live Discord, filesystem/antivirus, Docker, microphone, Minecraft, GPU/STT 서비스는 실행하지 않았다.
