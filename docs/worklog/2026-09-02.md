## 선택 기능을 필수 작업으로 오판한 기록과 교정

- 기존 장기기억은 이미 Obsidian-compatible Markdown vault를 durable source로 사용한다. private archive는
  30일 exact text/final STT·참여 event·사용자별 열람/삭제를 위한 별도 선택 기능인데, 미완료 plan 항목만 보고
  현재 필수 작업으로 잘못 판단해 BitLocker preflight로 진행했다.
- 영향은 read-only host 확인과 fail-close provision 시도, launcher recovery 보존 수정·문서화까지다. BitLocker,
  archive root/key/TLS, Docker/Evelyn service와 Discord Gateway의 실제 변경·기동은 0이다.
- 교정: private archive와 BitLocker는 기본 OFF로 유지한다. 사용자가 exact 30일 원문 기록과 사용자별
  열람·삭제를 명시적으로 요구하지 않으면 재개하지 않는다. 기억 관련 후속은 기존 Markdown vault의
  deletion-current lineage와 live recall을 별도 범위로 다룬다.
- 재발 방지: `진행해`를 미완료 계획 전체의 승인으로 해석하지 않는다. 먼저 현재 사용자 목표가 기존 기능으로
  충족되는지 확인하고, 선택 기능·보안 설정·외부 효과는 목적과 필요성을 명시적으로 확인한다.
