# 2026-08-09 작업 기록

## Mindcraft atomic process-local safety boundary

- default history를 bounded process-local turn으로 제한하고 `load_memory=false`로
  고정했다. Compose의 `bot_memory/mindcraft` mount와 planner recovery state path를
  제거했으며 recovery persistence는 no-op이다.
- pre-existing `memory.json`, archive와 legacy log는 읽거나 현재 generation으로
  rebase하거나 삭제하지 않는다. restart restore와 user data cleanup을 구현했다고
  주장하지 않는다.
- generation exposure가 turn 첫 await 전부터 awaited final route/action sink까지 유지된다.
  inter-agent pause/classifier와 timer queue도 같은 경계를 사용한다. exposure 중 clear는
  busy로 닫히고 성공한 clear는 history/queue, recovery/action-mode, self-prompt,
  last-sender와 goal-manager의 raw execution/gate/observation 상태를 함께 초기화한다.
- goal/status artifact는 command/result/reason/argument 원문을 쓰지 않고 enum code와
  count/boolean/fixed error code만 남긴다. Node writer와 Python status owner는 legacy raw
  projection을 재사용하지 않는다.
- detached inter-agent conversation 전송과 종료된 conversation timer를 whole-turn 경계에
  결합해 clear 뒤 사후 전송·ghost turn을 막았다.
- Google translation 경로는 local identity transform으로 교체했다. Node child
  stdout/stderr는 `DEVNULL`이며 기존 log는 변경하지 않는다.
- 이번 증분은 source-level 경계다. Docker image, 실제 Minecraft login/action,
  live clear는 실행하거나 검증하지 않았다. 문서에는 private content를 기록하지 않았다.
- 검증: Mindcraft 25개, Minecraft 227개(skip 11), Voyager 24개, runtime 782개(skip 4),
  CI-equivalent 전체 3,138개(skip 22), JS 구문과 Docker patch stack 적용이 통과했다.

## Mindcraft broker와 Local Bridge software playback completion

- Mindcraft Node planner의 direct local/router/Codex model 호출을 제거하고 전용 token-file

  억제한 fixed `Control Page start failed` wrapper를 발생시킨다.
- Control Page startup·runtime lifecycle·Discord event 인접 76개와 CI-equivalent 전체
  3,233개(skip 22), Python 구문·독립 Ponytail 감사·diff check가 통과했다. 실제 Control
  Page·Discord·마이크·스피커·Minecraft·Docker는 시작하지 않았다.

## Mindcraft disconnect-reason output privacy

- Minecraft server가 제공한 known·unknown kick reason 원문이 Mindcraft handler return,
  Docker console과 MindServer `bot-output`에 복제되는 경계를 synthetic reason으로 재현했다.
- raw reason은 내부 classification에만 사용한다. known reason은 fixed classified message,
  unknown reason은 fixed `Unclassified connection failure.`만 output과 return에 남기며 기존
  type·fatal·종료 의미는 유지한다.
- build-gated Node behavior test, JavaScript 구문 2개, Mindcraft/broker Python 30개와
  CI-equivalent 전체 3,233개(skip 22), 독립 Ponytail 감사·diff check가 통과했다. 실제
  Minecraft·Mindcraft·Docker는 시작하지 않았다.

## Cognitive background-refresh failure-log privacy

- Main LLM context가 예약한 background cognitive refresh 실패 로그에 session key,
  reason과 예외 원문·경로가 복제되는 경계를 synthetic failure로 재현했다.
- 실패 로그는 fixed `[COGNITIVE] background refresh failed` prefix와 exception type만
  남긴다. cancellation rethrow와 exact owned-task cleanup 의미는 유지한다.
- cognitive refresh·context assembly 인접 45개와 CI-equivalent 전체 3,234개(skip 22),
  Python 구문·독립 Ponytail 감사·diff check가 통과했다. 실제 사용자 memory·LLM·Discord·
  마이크·스피커·Minecraft·Docker는 시작하거나 변경하지 않았다.
